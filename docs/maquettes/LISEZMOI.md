# Maquettes CAC PERFORM V2

Référence visuelle des écrans restants. Ce sont des maquettes, pas du code à copier :
l'implémentation se fait en Vue 3 + Tailwind, selon la charte d'interface de CLAUDE.md.

- 0_Barre_laterale : barre latérale de la mission (nouveau bloc Circularisation, Journal d'audit, Paramètres)
- 1_Fiabilite_IPE : version améliorée (circuit de revue, colonne Remarques, panneau latéral de qualification)
- 2_Selection_tiers : Module 2 (CIR-01, SEUILS-01, ECH-01)
- 3_Memo_selection : mémo de sélection
- 4_Courriers : Module 3, modèles, aperçu, génération et envoi
- 5_Suivi_reponses : relances J0 / J+15 / J+30 / J+45 et saisie des réponses
- 6_Journal_audit : journal non modifiable
- 7_Parametres : réglages administrateur

Les valeurs entre crochets ([montant], [date]) sont des emplacements : elles viennent des données réelles.
Les balises <dc-import>, <sc-for> et <sc-if> sont propres à l'outil de maquette : à ignorer.
